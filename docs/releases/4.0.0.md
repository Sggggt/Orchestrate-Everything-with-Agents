# OEA 4.0.0

Model connections and write-only credentials are managed in a user API Box. Agent declarations reference named entries; main-instance model selection applies to subsequent tasks, while managers select only through their settings. Accepted Runs retain resolved model versions.

Portable plugins combine MCP, Skills and declared platform capabilities. Standalone components remain available in the Plugins page. Built-in Plugin Creator and Agent Factory reuse the same domain operations as SDK, HTTP and external control MCP clients. Agent creation requires an explicit capability grant and retains existing root-budget ownership; no new budget mechanism is introduced.

The control protocol is 4.0 and state schema revision is 6. OAP 1.0, graph format and native SDK protocol remain independent. Upgrade stopped earlier state into a verified new target; Agent API fields are removed after Box import, and only unreferenced old secrets are cleaned. Source data and original files remain available for recovery.

The workbench uses compact plugin, model and integration directories with separate plugin settings. Model selection is saved on the first click. External Agent messages appear on the left of group chat; browser user messages appear on the right.

Packages include precompiled native components for Windows x64 and Linux x64, a source archive and SHA-256 checksums. Python 3.12 or newer is required. Windows also requires the Microsoft Visual C++ v14 x64 runtime and a compatible PSEC environment. Linux native execution requires Bubblewrap and its documented network dependencies. See the [installation guide](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v4.0.0/docs/getting-started.md).
