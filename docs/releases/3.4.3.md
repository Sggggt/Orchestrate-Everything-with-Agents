# OEA 3.4.3

- Send a notification by Agent ID or to an exact instance. The Host selects the sole reachable instance or, when several are reachable, the sole reachable manager. Receipts identify ambiguous recipients.
- The **通信与协调** tab provides a compact form for partner grants, delegation and manager settings. The group chat can add a configured manager instance in collaborative mode. Authenticated control MCP clients use their Host access for messaging.
- Model and browser progress connections each allow up to five automatic reconnect attempts. The conversation displays **正在重连** during recovery. Model attempts retain their receipts under the original Run and budget. Browser progress resumes from the original event cursor.

## Installation

Download the wheel for Windows x64 or Linux x64 from the release assets and verify its SHA-256 against `SHA256SUMS`. The assets also include the source distribution. Python 3.12 or newer is required.

```console
python -m pip install "./orchestrate_everything_with_agents-3.4.3-py3-none-win_amd64.whl[web,mcp,workbench]"
oea serve --allow-commands
```

On Linux, use the `linux_x86_64` wheel filename. Run `oea open` in another terminal to open the workbench. See the [installation guide](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v3.4.3/docs/getting-started.md) for Windows runtime and Linux sandbox prerequisites.

## Existing installations

State schema revision 4, control protocol 3.0, OAP 1.0 and graph format 1 carry forward from 3.4.2. Stop the previous Host before upgrading. A state directory already at revision 4 can be reused. For earlier state formats, see [offline migration](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v3.4.3/docs/migration/README.md).
