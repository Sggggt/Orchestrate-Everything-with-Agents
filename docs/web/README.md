# web 模块接口

本机 HTTP 接入和原版 Web 管理界面。

源码：[src/oea/web/](../../src/oea/web/)

## Python 接口

- `web/app.py`：`Call`
- `web/app.py`：`create_app(state_dir=None, *, host=None, allow_commands=False, client_url=None)`

## 依赖与边界

依赖模块：catalog、contracts、runtime、security、storage、workspace。

跨模块调用使用明确的 Python 对象和注入的服务；HTTP、MCP 可调用操作以共享操作注册表为准。执行权限由实际服务边界校验。

## 管理界面适配

Agent 设置面向桌面使用，分为“概览与画布、模型与职责、常用能力”。概览显示配置可用性、当前生效版本及正在查看的候选草稿，不展示历史运行状态。配置检查与主动模型连接测试分别说明，不根据历史运行推断就绪。

整个节点预览区域可点击并通过键盘进入全屏工作台。工作台提供节点库、画布、属性/状态面板、子图面包屑和按需展开的试运行区。节点位置保存在声明中，视口移动不产生未保存标记。保存与离开有明确状态，未保存内容离开前可保存、放弃或继续编辑；SSE 更新不覆盖本地修改。

候选草稿按 Agent 归属筛选，支持创建、复制、重命名和删除。选择只切换预览，确认“切换版本”后依次调用共享发布和绑定操作。发布成功但绑定失败仍保留原版本，并明确提示。删除草稿保留发布历史、绑定和 Run；删除及切换均需弹窗确认。旧共享架构通过复制继续编辑。版本切换默认允许，仅改变后续新接受任务；历史运行或用量待核对不禁用切换，原运行恢复沿原图。其他未保存表单字段保持。

设置页读取缓存拓扑，完整声明仅在编辑、复制或重命名时按需加载。13 类原生 Agent 节点、状态/reducer、映射、分支、循环、纯计算并行、子图及中断沿现有 LangGraph 契约执行。已注册代码图只读；浏览器不执行上传的 Python 字符串。试运行使用专用会话和独立实例、原权限和预算，节点结果通过原回执读取，中断继续沿原 Run。

工作台为独立应用内路由，支持刷新及浏览器返回。采用短过渡，尊重减少动态效果，不增加轮询或模型格式修复。节点 Schema 按类型读取并在编辑器会话内复用。未展示的高级配置完整保存。

工作台“最近任务”和“需要我处理”标题右侧提供箭头按钮，打开紧凑分页表格弹窗；默认当前项目全部会话（含已归档），可切到当前会话。待办独立查询，包含已完成任务的待核对用量。复选框支持跨页多选，批量“标记已处理”持久保存 handling_state，并从待办及计数移除。全部历史保留原执行状态和回执，状态变化产生新待办；通过 SSE 刷新，不定时轮询。

工作流编辑区限制在当前可用视口内，画布和底部操作保持在同一屏幕；长节点设置及工作流目录使用各自的滚动区域。画布尺寸变化时重新适配节点，同版本定义刷新保留当前视图，视图调整不产生未保存标记。

保留工作台导航、标签、表单与弹窗结构。MCP 目录通过共享操作注册表读取本机 Codex TOML、选择导入、软移除服务；服务目录和调用历史按返回的游标加载后续页，秘密值不回显。导入保存成功与连接发现是独立操作。

项目菜单提供名称修改和需要精确名称确认的永久删除，项目不进入回收站。会话归档后从活动选择、打开分页和快捷搜索中移除，当前会话切换到下一活动会话或空态。回收站独立分页读取当前项目的已归档会话并恢复，不依赖活动列表缓存。项目删除事件可在SSE中读回并结束原流；同ID重建不将旧删除事实当作新项目删除。上传附件与 RunSpec.artifact_ids 继续沿用既有显式分配流程。

实例对话以连续正文展示模型回复，执行活动按需展开读取原始回执，较长历史正文保留完整内容入口。当前 Run 使用既有 SSE 增量更新；进入实例或群聊，以及出现新消息时滚动至最新。没有新消息的刷新保留阅读位置，历史分页保留位置。输入草稿和展开状态不因刷新丢失；输入法组合输入的回车不会发送消息。

Agent 没有实例时先打开空对话，首次发送才创建稳定实例；只有一个实例时直接进入，多个实例时先选择。任务弹窗在一个视图展示状态、时间和用量，提供打开原对话入口。设置入口使用齿轮，导航保留功能名称；图标操作提供可访问名称和提示。

群聊按发送方左右排列，每条消息显示实际收件实例。`messages.list` 的 `recipient_instance_ids` 来自接受时冻结的投递记录，不根据当前成员重新推算，也不推断原消息使用了Agent或全体选择器。

任务元信息分别展示预算核算、供应商报告、估算、在途预留与待核对用量。未知报告显示“未知”；调用尝试与收到响应、生成完成及失败分开。错误提示直接使用共享 diagnostic 的根因、发送事实和完整性，提供带 attempt_id 的原回执入口。历史折叠只影响展示，生成不完整及原始捕获截断另行标记；产物预览的 1 MB 显示上限与原始捕获上限也分别说明。

未读徽标位于独立对话的 Agent 右侧、总览 Agent 右上角和协作消息标签右侧。状态标签紧跟 Agent 名称。只有可见窗口中显示到最新位置的对话或群聊才推进对应已读游标；刷新后沿用服务端保存的位置。群聊中 manager 头像打开该 Agent 的实例选择，实例头像进入对应对话，选择弹窗按服务端游标加载更多实例。

模型流按 action/attempt 和顺序号累积，首段、首次工具及终态立即刷新。重连或顺序缺口通过 `runs.response` 补读原响应，分页固定内容版本；补读期间缓存同连接代次的更新，旧连接或旧 attempt 的尾块不能覆盖新响应。已闭合的 Markdown 块保留原 DOM，仅重绘活动末段；原始正文及最终 Markdown 语义不变。

任务详情展示当前输入估算、Schema 成本、加载数量、缩减前后值、供应商偏差与缓存命中，并显示最近阻断及实际停止事实。恢复表单可设置本次图执行步数上限，沿用原检查点和累计预算。图节点标题及 map 标签作为确定性展示元信息，原 ID 保留在详情中。
