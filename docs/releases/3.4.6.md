# OEA 3.4.6

- Model input includes one copy when an MCP tool returns the same JSON as both a text block and structured data. Large results use a preview or a reference, with the full original response available in its action receipt.
- Structured MCP errors carry their reported cause, stage and available field or capability details into the next model request. Repeated failures of the same kind prompt the Agent to adjust its approach within the existing budget and execution rules.
- The bundled Codex Skill and MCP guide describe how to inspect a blocker and read the original tool receipt.

## Installation

Download the Windows x64 or Linux x64 wheel and verify its SHA-256 against `SHA256SUMS`. A source archive is also available. Python 3.12 or newer is required.

```console
python -m pip install "./orchestrate_everything_with_agents-3.4.6-py3-none-win_amd64.whl[web,mcp,workbench]"
oea serve --allow-commands
```

On Linux, use the `linux_x86_64` wheel. Run `oea open` in another terminal to open the workbench. See the [installation guide](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v3.4.6/docs/getting-started.md) for Windows runtime and Linux sandbox prerequisites.

## Existing installations

This release uses state schema revision 4, control protocol 3.0, OAP 1.0 and graph format 1. Stop the previous host before upgrading. A state directory already at revision 4 can be reused. For earlier state formats, see [offline migration](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v3.4.6/docs/migration/README.md).
