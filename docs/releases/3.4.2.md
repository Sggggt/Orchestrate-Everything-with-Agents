# OEA 3.4.2

This release adds a full-screen Agent canvas with candidate drafts, explicit version activation and draft deletion. Default-version changes apply to future tasks while existing tasks retain their original architecture. The workbench provides paginated task history and multi-select handling of pending items without changing execution receipts or accounting.

## Downloads

- Windows x64: `orchestrate_everything_with_agents-3.4.2-py3-none-win_amd64.whl`
- Linux x64: `orchestrate_everything_with_agents-3.4.2-py3-none-linux_x86_64.whl`
- Source distribution: `orchestrate_everything_with_agents-3.4.2.tar.gz`
- SHA-256 checksums: `SHA256SUMS`

Download the wheel matching your system from this release's assets. Python 3.12+ is required. Windows native execution requires Windows 11/PSEC support and the Microsoft Visual C++ v14 x64 runtime. The Linux wheel is built on Ubuntu 24.04 and requires a compatible C runtime plus Bubblewrap and the documented networking dependencies; it is not a manylinux wheel.

Install the downloaded wheel with the optional interface dependencies:

```console
python -m pip install "./orchestrate_everything_with_agents-3.4.2-py3-none-win_amd64.whl[web,mcp,workbench]"
oea serve --allow-commands
```

For Linux, use the `linux_x86_64` filename instead. In another terminal, run `oea open` to open the authenticated workbench. Full prerequisites and source-build instructions are in the [installation guide](../getting-started.md).

## Existing installations

State schema revision 4 adds task-handling state. Control protocol 3.0 and OAP 1.0 are unchanged. Stop an older host and use the documented [offline state upgrade](../migration/README.md) into a new external directory before starting this version. Preserve the old state and verify the migrated target; installation does not automatically migrate or overwrite user data.
