# OEA 3.4.5

- The token input budget deducts provider-confirmed cache hits at settlement. Dispatch reserves the full estimated input, and cache writes count as input. An explicitly configured total-input ceiling still includes cached usage. Provider fees use their configured rates.
- Instance conversations load up to 100 visible messages per page and keep the reading position when loading older messages. The collaboration feed can load up to 250 older messages at a time.
- Long replies display their full saved text automatically. Select and disclosure controls use line chevrons.
- The shared `instances.history` and `instances.message` operations support paginated conversations and reading a single retained message. The bundled Codex Skill documents both operations.

## Installation

Download the Windows x64 or Linux x64 wheel from the release assets and verify its SHA-256 against `SHA256SUMS`. The assets also include the source distribution. Python 3.12 or newer is required.

```console
python -m pip install "./orchestrate_everything_with_agents-3.4.5-py3-none-win_amd64.whl[web,mcp,workbench]"
oea serve --allow-commands
```

On Linux, use the `linux_x86_64` wheel filename. Run `oea open` in another terminal to open the workbench. See the [installation guide](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v3.4.5/docs/getting-started.md) for Windows runtime and Linux sandbox prerequisites.

## Existing installations

This release uses state schema revision 4, control protocol 3.0, OAP 1.0 and graph format 1. Stop the previous host before upgrading. A state directory already at revision 4 can be reused. For earlier state formats, see [offline migration](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v3.4.5/docs/migration/README.md).
