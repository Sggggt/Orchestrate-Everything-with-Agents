# OEA 3.4.4

- Recover a missing `exec_command` receipt from the confirmed exit and saved output. The host preserves the original action ID, exit code and output. A recovered Run can continue using that receipt.
- When a Run is resumed during a tool turn, model input places the resume guidance after the paired tool results. The same projection repairs the order for existing history and keeps the original records and cursors intact.

## Installation

Download the Windows x64 or Linux x64 wheel from the release assets and verify it against `SHA256SUMS`. The assets also include the source distribution. Python 3.12 or newer is required.

```console
python -m pip install "./orchestrate_everything_with_agents-3.4.4-py3-none-win_amd64.whl[web,mcp,workbench]"
oea serve --allow-commands
```

On Linux, use the `linux_x86_64` wheel filename. Run `oea open` in another terminal to open the workbench. See the [installation guide](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v3.4.4/docs/getting-started.md) for Windows runtime and Linux sandbox prerequisites.

## Existing installations

State schema revision 4, control protocol 3.0, OAP 1.0 and graph format 1 carry forward from 3.4.3. Stop the previous host before upgrading. A state directory already at revision 4 can be reused. For earlier state formats, see [offline migration](https://github.com/Sggggt/Orchestrate-Everything-with-Agents/blob/v3.4.4/docs/migration/README.md).
